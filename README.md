# Грань — сайт сообщества

Статический сайт на HTML, CSS и JavaScript. Сборка не требуется. Открыть index.html или запустить любой локальный HTTP-сервер.

## Сведения
Содержание сверено 01.11.2026 с Discord проекта: информацией о подключении, правилами и новостями. Официальные площадки: [Boosty](https://boosty.to/edge_server), [Telegram](https://t.me/edgenotSMP). Статус сервера и текущий онлайн сайт не отслеживает.

Постоянная Discord-ссылка приглашения не предоставлена. Ссылки на каналы предназначены участникам, для новых игроков указан официальный бот вопросов.

## Материалы
Логотип и скриншоты — из Discord «Грань». Иллюстрации world-cover и story-art — с официальной страницы проекта на Boosty. Материалы принадлежат своим авторам, не использовать в других проектах без их разрешения. Сайт не является продуктом Mojang или Microsoft.

## Поведение
IP копируется через Clipboard API. Если браузер запрещает копирование, адрес выделяется для ручного копирования. Галерея поддерживает клавиатурные стрелки и Escape. Мобильное меню и анимации учитывают reduced motion. Данные посетителей не собираются; внешних аналитических скриптов нет. Шрифты загружаются с Google Fonts, предусмотрены системные замены.

## Обновление
IP находится в app.js (SERVER_IP) и двух видимых блоках index.html. Версию, сборки и правила следует сверять с информационными каналами проекта. Discord приглашение можно добавить после получения постоянного адреса.
